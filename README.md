# Лабораторная работа №4

## Авторы

Климов Дмитрий ПИ-241

## Описание

Консольное приложение для проверки доступа пользователя к ресурсам.

Пользователь указывает:
- логин;
- пароль;
- действие (`read`, `write`, `execute`);
- путь к ресурсу;
- запрашиваемый объём.

Программа проверяет данные пользователя, существование ресурса, права доступа и допустимый объём.

## Требования

Для сборки и запуска необходимы:
- установленный JDK;
- компилятор Kotlin (`kotlinc`);
- библиотека `kotlinx-cli`, расположенная в `lib/kotlinx-cli-jvm-0.3.6.jar`.

## Сборка

Для сборки проекта используется скрипт:

```bash
./build.sh
```

После успешной сборки создаётся исполняемый файл `app.jar`.

## Запуск

Приложение можно запустить с помощью скрипта:

```bash
./run.sh --login alice --password qwerty --action read --resource A.B.C --volume 10
```

Также доступен запуск непосредственно через JAR:

```bash
java -jar app.jar --login alice --password qwerty --action read --resource A.B.C --volume 10
```

Для просмотра справки:

```bash
./run.sh --help
```

Или:

```bash
java -jar app.jar --help
```

## Аргументы командной строки

| Аргумент | Описание | Пример |
|---|---|---|
| `--login` | Логин пользователя | `alice` |
| `--password` | Пароль пользователя | `qwerty` |
| `--action` | Действие над ресурсом | `read` |
| `--resource` | Путь к ресурсу | `A.B.C` |
| `--volume` | Запрашиваемый объём, целое число | `10` |
| `--help`, `-h` | Вывод справки | `--help` |

## Коды завершения

| Код | Значение |
|---:|---|
| `0` | Операция выполнена успешно |
| `1` | Запрошена справка или отсутствуют обязательные аргументы |
| `2` | Неверный пароль |
| `3` | Пользователь не найден |
| `4` | Неизвестное действие |
| `5` | Доступ запрещён |
| `6` | Ресурс не найден |
| `7` | Некорректный формат данных |
| `8` | Запрошенный объём превышает допустимый |

## Тестирование

Для запуска автоматических тестов используется команда:

```bash
./test.sh
```

Тесты проверяют успешный доступ, обработку справки, ошибки авторизации, неизвестные действия, отказ в доступе, отсутствие ресурса, некорректный формат и превышение допустимого объёма.
