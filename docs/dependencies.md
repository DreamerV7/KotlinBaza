# Зависимости

Зависимости управляются Maven через pom.xml: Spring Boot Core, Kotlin, kotlinx-cli, H2, JUnit и JaCoCo. Spring Boot Starter включает SLF4J и Logback. Maven Wrapper фиксирует Maven 3.9.11. Исполняемый JAR включает зависимости; target/dependency содержит библиотеки для утилиты инициализации H2.
